# ADR-0005: Brand name ShaMallya

- Status: Proposed
- Date: 2026-10-30

## Context
The project needs a memorable, personal, ownable identity separate from the working title "Token Forge".

## Decision
- Brand: **ShaMallya** (from Shamala + Mallya, stylised ShaMallya).
- Working/project name: Token Forge.
- Technical identifiers are lowercase: token namespace `shamallya.`, npm scope `@shamallya`, packages `@shamallya/tokens` and `@shamallya/ui`.

## Consequences
- One brand across tokens, packages, showcase and case study.
- Name availability (npm scope, GitHub organisation, domain) must be confirmed before launch (PRD Q7, Q8).
- Companies adopting the system can rebrand through a theme (architecture section 5) without renaming components.
